# Launcher clone

A personal, clean-room Android launcher inspired by the UX of Niagara Launcher: favorites, a wave-alphabet app list and inline notifications. No code, assets or copy from the original.

- `replica/recon.md`: screens, flows, components, data model (public sources only)
- `replica/features.csv`: feature matrix
- `replica/architecture.md`: stack, entry points, jobs, build order
- `replica/schema.sql`: on-device database schema (Room / SQLite)
